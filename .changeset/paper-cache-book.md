Use Diagram Design HTML for all new Sketchbook diagrams. Mermaid slides, slide focus, and the diagram-viewer camera are no longer supported. Static SVG decks, Markdown, math, code, and book navigation remain supported.

The package now exposes one skill, `sketchbook`. Use `/skill:sketchbook` in Pi instead of `/skill:sketchbook-create-diagrams` or `/skill:sketchbook-diagram-design`.

Sketchbook reports Mermaid content in an original page, chapter, or section without converting or deleting the source. See “Open older books” in the README to read both records with the verified recovery build.
